
# Inkscape - Vector Artwork You Can Resize

[![Open Inkscape](https://img.shields.io/badge/Open-Inkscape-0f766e?style=for-the-badge&logoColor=white)](https://nancydavisq370.github.io/.github/Inkscape)

## About Inkscape

Inkscape draws vector artwork: logos, icons, diagrams, and illustrations made of paths rather than a fixed grid of pixels. You use it for graphics you are designing. It does not include a pack of commercial logos, and tracing a picture you do not own does not make that picture yours.

A vector file stays sharp when you scale it for a small icon or a large print. That is the reason to use Inkscape instead of a paint program when the shape is what matters. Text can stay editable until you turn it into paths on purpose. Leave it as text while you are still changing the words.

Save the SVG. Export a PNG when a page or a shop needs a picture. The SVG is the file you will edit next week. The PNG is a snapshot.

## How to Use Inkscape

1. Start a new document at the page size you need.  
2. Draw or place shapes you created, and keep text as text until the wording is final.  
3. Save the SVG before you try a complex path effect.  
4. Export a PNG at the pixel size the destination asked for.  
5. Open the PNG in a viewer and confirm the edges are what you wanted.

---

## Features Included in Inkscape

- Path drawing for logos, icons, and diagrams  
- Text that stays editable until you convert it  
- Layers for grouping parts of your own design  
- Export to PNG at a size you choose  
- SVG as the working file you can reopen  
- Alignment tools so objects sit where you place them  
- A page size you set, rather than a single flattened bitmap  
- Undo during the session, plus the saved SVG as the real backup

---

## Troubleshooting

- The export looks blurry? You exported too few pixels. Export again at a larger size.  
- Text looks different on another PC? The font may be missing there. Convert to paths only when the words are final, and keep a copy with live text.  
- A file from someone else will not edit cleanly? It may be a flattened picture, not vectors. You cannot pull paths out of a photo.
